# Keyboard shortcuts

Press `Shift+/` (`?`) in the app to see the shortcuts available in the current workspace. Shortcuts written as `⌘` use Command on macOS and Ctrl on Windows; the app shows the right one for your platform. Shortcuts are ignored while you are typing in a text field.

## Global

| Shortcut | Action |
| --- | --- |
| `Space` | Enlarge the active photo |
| `Q` | Toggle the active photo in the export queue |
| `Shift+/` | Show keyboard shortcuts |
| `⌘1` / `Ctrl+1` | Switch to Browse |
| `⌘2` / `Ctrl+2` | Switch to Review |
| `⌘3` / `Ctrl+3` | Switch to Similarity |
| `⌘4` / `Ctrl+4` | Switch to Enhance & Export |
| `⌘5` / `Ctrl+5` | Switch to Stats |
| `⌘6` / `Ctrl+6` | Switch to Debug |
| `H` / `L` | Select the photo to the left / right |
| `J` / `K` | Select the photo below / above |
| `⌘S` / `Ctrl+S` | Save workspace file (desktop app, **File → Save Workspace File...**) |

## Review

| Shortcut | Action |
| --- | --- |
| `Q` | Toggle export queue |
| `⌘=` / `Ctrl+=` | Zoom in |
| `⌘-` / `Ctrl+-` | Zoom out |
| `⌘0` / `Ctrl+0` | Reset zoom |
| `↑` / `↓` | Resize the preview (when the preview divider has focus) |

## Similarity

| Shortcut | Action |
| --- | --- |
| `←` / `→` | Previous / next photo in the current similar group |
| `↑` / `↓` | Select the photo above / below in the similarity grid |

## Enlarged preview

| Shortcut | Action |
| --- | --- |
| `Esc` or `Space` | Close the enlarged preview |
| `←` / `→` | Previous / next similar photo |

## Enhance & Export (editor)

| Shortcut | Action |
| --- | --- |
| Hold `\` | Show the original (neutral RAW base) |
| `⌘Z` / `Ctrl+Z` | Undo |
| `⇧⌘Z` / `Shift+Ctrl+Z`, `Ctrl+Y` on Windows | Redo |
| `Esc` | Leave full screen |
| Double-click a slider | Reset that slider |
| Double-click the Tone/Color pad | Reset the pad |
| Arrow keys on the focused pad | Nudge the pad (`Shift` for larger steps) |
| Arrow keys / `Home` / `End` / `Page Up` / `Page Down` on a focused slider | Adjust the slider (one undo step per key press) |
