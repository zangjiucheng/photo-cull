# v0.2.1 — 应用内自动更新

## 新功能

- 每次启动自动检查 GitHub Releases 上的新版本；也可以通过菜单 **AI Photo Culling → Check for Updates...** 手动检查。
- 有新版本时显示更新说明，可以选择更新、稍后再说或跳过此版本。
- 确认更新后，下载对应架构的 zip，按 `SHA256SUMS.txt` 校验，并核对包内版本号；之后可以立即重启安装，也可以等下次退出时再安装。替换 `.app` 失败会自动恢复旧版本。

## 发布

- 发布流程同时构建 DMG 和更新用的 zip，两者都写入 `SHA256SUMS.txt`。

## 说明

- v0.2.0 及更早的版本没有更新器，需要手动安装一次 v0.2.1；从 v0.2.1 开始，之后的版本都能在应用内更新。
- 自动替换要求应用位于可写目录，例如 `/Applications`。如果直接从 DMG 中运行，会改为打开发布页。
- 设置 `AI_CULLING_DISABLE_UPDATES=1` 可以关闭更新检查。
- 仍然没有配置 Developer ID 签名和公证。
