# v0.2.1 — In-app auto-update

## New features

- Checks GitHub Releases for a new version on every launch; you can also check manually from the menu **AI Photo Culling → Check for Updates...**.
- When a new version is available, the release notes are shown and you can choose to update, be reminded later, or skip this version.
- After you confirm, the zip for your architecture is downloaded, verified against `SHA256SUMS.txt`, and its bundled version number is checked; you can then restart to install right away, or let it install the next time you quit. If replacing the `.app` fails, the previous version is restored automatically.

## Release

- The release workflow now builds both the DMG and the zip used for updates, and both are listed in `SHA256SUMS.txt`.

## Notes

- v0.2.0 and earlier have no updater, so v0.2.1 has to be installed manually once; from v0.2.1 on, every later version can be updated in the app.
- Automatic replacement requires the app to be in a writable folder such as `/Applications`. If it is run directly from the DMG, the release page is opened instead.
- Set `AI_CULLING_DISABLE_UPDATES=1` to turn off update checks.
- Developer ID signing and notarization are still not configured.
