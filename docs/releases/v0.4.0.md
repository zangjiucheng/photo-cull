# v0.4.0 — Windows, RAW finishing and a recoverable library

## Windows

- Windows 10/11 (x64) installer: per-user, no admin rights, with in-app updates that check the installer's SHA-256, install silently after you quit and relaunch.
- Shortcuts use Ctrl outside macOS (labels and hints follow), Ctrl+Y redoes, and **Help → Check for Updates** replaces the macOS app menu item.
- The AI runtime works on PCs without the Visual C++ Redistributable: the app ships Microsoft's runtime DLLs and places them next to torch (this also repairs existing installs).
- No console window opens next to the app.
- The live preview is split into a develop pass and a sharpen pass. Under Direct3D a redraw took up to 1.4 s, long enough for the GPU watchdog to reset and black out Enhance & Export; it now takes about 0.13 s, with the same output.

## RAW finishing

- Native 100% detail with Retina pixel mapping, pan, original comparison and clipping.
- RGB/luminance histogram of the edited crop.
- A local gradient with feather, invert, exposure, highlights and warmth.
- Selective color and a neutral-gray white-balance picker.
- Recipes record their engine and RAW profile versions, so saved edits keep rendering the same.
- Direct crop handles on the whole-image view and two-point horizon leveling.
- Same-scene exposure matching to a reference photo: previewed before applying, capped at ±1 EV, aware of highlights, and skipping night or silhouette mismatches.

## A recoverable library

- **File → Back Up Library…** writes ratings, edits, presets and versions into one file. Restore checks its checksum and SQLite integrity, upgrades older backups and keeps your current library as a copy.
- Reconnect a workspace whose folder moved or whose disk was renamed.
- Presets live in the library (moved once from this computer's local storage) with rename and JSON import/export.
- Named versions per photo that store recipes only.
- Exports resume after a crash without redoing finished files, write each file atomically and can retry only the failures.

## Settings, updates and first run

- The Debug tab is now **Settings** (`⌘,` / `Ctrl+,`).
- Choose the Python for the AI runtime or let the app find one. If none is installed it downloads a verified private Python 3.12.
- An update channel: **Stable**, or **Nightly** for a build of the latest code each night.
- The version, commit and build time are shown in Settings and About, with **Copy Version**.
- A first-run welcome guide walks through the workflow and offers the optional AI runtime install. It shows once.
- Export folders and unsaved-edit recovery survive a restart (the app keeps the same local port between launches).

## Fixes

- Similarity recomputes groups with CLIP once the AI runtime is installed, instead of showing "CLIP unavailable" from cached results. Without the runtime, the message says how to get CLIP.
- Enhance & Export no longer crashes when the export queue is empty.
- A crash in one workspace no longer blanks the window: the workspace shows the error with **Try Again**, and errors are written to `renderer.log`.
