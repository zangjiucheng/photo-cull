# v0.3.1 — More styles and a new icon

## Styles

- 18 Apple Photos-style looks, grouped like Apple Photos:
  - **Undertones**: Standard, Amber, Gold, Rose Gold, Neutral, Cool Rose
  - **Moods**: Vibrant, Natural, Luminous, Dramatic, Quiet, Cozy, Ethereal, Warm Sunset, Cool
  - **Black & White**: Classic B&W, Muted B&W, Stark B&W
- Styles can now use tint and black point, so looks like Rose Gold and Stark B&W are possible. The live preview and exports match exactly: the CPU/GPU parity check passes all 43 scenarios with a maximum error of 0/255.
- Styles that already existed keep their exact settings, so saved edits render the same. Only some labels changed (Original → Standard, Warm sunset → Warm Sunset, Black & white → Classic B&W).
- Style thumbnails now share a single offscreen renderer. One WebGL context per thumbnail would have gone over the browser's limit and could drop the main preview.

## App icon

- New flat black-and-white icon: viewfinder corners framing a four-point star. It replaces the old teal icon in the Dock, the app bundle and the browser tab.

## Docs and website

- README and all docs are now in English. New guides: getting started, editing, keyboard shortcuts and development.
