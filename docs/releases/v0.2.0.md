# v0.2.0 — Quick RAW editing

Go straight from culling to color and export: the new Enhance & Export workspace gives you a single large photo, six everyday sliders, Auto enhance, and a photo strip along the bottom.

## New features

- Adjust Exposure, Brilliance, Highlights, Shadows, Vibrance, and Warmth instantly; the advanced section adds Black point, Contrast, Dehaze, Tint, Saturation, and Detail.
- Five styles are previewed on thumbnails of the current photo and have their own strength; the neutral zero point no longer tints skies and foliage by default.
- Auto enhance with adjustable strength, hold to view the original, double-click to reset a single control, per-photo undo/redo, and autosave.
- Non-destructive crop, common aspect ratios, straighten, and a rule-of-thirds grid.
- Selective copy, batch sync, per-device personal presets, and Share JPEG / Archive TIFF export presets.

## Processing and reliability

- RAW files are now developed at 16 bits with float32 base processing; preview and export share the same source and color math.
- Persistent WebGL resources keep continuous dragging smooth, loads can be cancelled, and responses for an old photo or old recipe can no longer overwrite the current view.
- JPEG and 16-bit TIFF embed an sRGB ICC profile, keep supported capture metadata, and update orientation and dimensions; GPS is not copied.
- The legacy recipe algorithm is preserved; fixed autosave loading overwriting recipes and the black first style thumbnail.
- Traditional noise reduction and runtime fallbacks are labeled accurately; basic editing does not need the optional AI runtime.
- Added the README and development/release notes; CI now includes the frontend production build, and release packages ship with a SHA-256 checksum file.

## Verification and scope

Locally verified: 75 Python tests, 19 frontend tests, the TypeScript/Vite build, 30 CPU/GPU pixel comparisons, and a preliminary check of 24 DJI DNGs at 4000×3000. The standalone packaged backend has completed real RAW development and batch export.

A macOS Apple Silicon DMG is provided; Developer ID signing and notarization are not configured. High-ISO real night scenes, 48 MP DNGs, long sessions switching through many photos, the full desktop interaction matrix, and the optional model runtime still need further acceptance testing. See the [implementation and validation record](../validation/quick-raw-editor.md).

Upgrading keeps using the local database and photo folders; keeping a backup of the database is recommended. Originals are never overwritten by editing or export, and old recipes keep working.
