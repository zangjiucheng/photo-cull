# v0.2.0 — 快速 RAW 调色

从选片直接完成调色与导出：新的 Enhance & Export 工作区提供单张大图、六个常用滑杆、自动增强和底部照片条。

## 新功能

- 即时调整曝光、鲜明度、高光、阴影、自然饱和度和冷暖；高级项包含黑位、对比、去雾、色调、饱和度与细节。
- 五种风格使用当前照片缩略图，提供独立强度；中性零点不再默认给天空和植被染色。
- 自动增强可调强度，支持按住查看原图、单项复位、逐片撤销重做和自动保存。
- 非破坏裁切、常用画幅、拉直与三分网格。
- 选择性复制、批量同步、设备个人预设，以及 Share JPEG / Archive TIFF 导出预设。

## 处理与可靠性

- RAW 改为 16 位显影与 float32 基础处理，预览和导出共享来源及调色数学。
- 持久 WebGL 资源支持连续拖动，加载可取消，旧照片或旧配方的响应不会覆盖当前画面。
- JPEG 和 16 位 TIFF 嵌入 sRGB ICC，保留支持的拍摄元数据，更新方向与尺寸；不复制 GPS。
- 保留旧配方算法；修复自动保存载入覆盖与首次风格缩略图黑屏问题。
- 准确标注传统降噪和运行时回退；基础调色无需可选 AI runtime。
- 新增 README、开发与发布说明；CI 增加前端生产构建，发布包附带 SHA-256 校验文件。

## 验证与范围

本地通过 75 项 Python 测试、19 项前端测试、TypeScript/Vite 构建、30 组 CPU/GPU 像素对比，以及 24 张 4000×3000 DJI DNG 的初步检查。独立打包后端已完成真实 RAW 显影和批量导出。

当前提供 macOS Apple Silicon DMG，未配置 Developer ID 签名或公证。高 ISO 真夜景、48 MP DNG、长期大量切图、完整桌面交互矩阵和可选模型 runtime 仍待进一步验收。详见 [实现与验收记录](../validation/quick-raw-editor.md)。

升级沿用本机数据库与照片目录，建议保留数据库备份。原片不会被编辑或导出覆盖；旧配方可继续使用。
