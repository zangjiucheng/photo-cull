# v0.3.0 — 全新黑白界面、Tone/Color 控制板与更快的处理

## 界面

- 整个应用改为统一的扁平黑白风格：纯黑背景、细分隔线，白色是唯一的强调色，只有星级（黄）和删除（红）保留功能色。去掉了卡片套卡片、渐变和装饰性阴影。
- 启动页、Browse 工具栏、缩略图、Review、Similarity、Inspector、编辑器、Stats、Debug 和快捷键面板都已重做，功能和快捷键保持不变。
- Browse 页左栏不再重复显示一遍缩略图；Inspector 改为键值列表；编辑器里导出是唯一的主按钮。

## 调色

- 新增 Apple 式 Tone/Color 2D 控制板（竖轴 More Tone ↔ Softer，横轴 Muted ↔ Vivid）。拖动时，反差、黑位、阴影、高光、鲜明度、自然饱和度、饱和度滑杆会一起移动。
- 每张照片的移动方向，由直方图和肤色/天空识别结果决定：暗部已经很深时不再往下压，高光接近溢出时先保护高光，天空和人像少加饱和度。
- 拖完可以直接微调任意滑杆，之后再拖控制板会保留你的微调。双击复位，方向键可微调。

## 性能

以下优化的输出像素与之前完全一致。

- 调色、色调曲线、sRGB 编解码按行分块，多线程并行计算；缩放三个通道并行处理。
- 编辑器缓存缩小后的基准图：切回已打开过的照片从约 2.7 秒降到约 0.01 秒，Auto 和控制板分析降到几十毫秒，预览渲染从 0.7 秒降到 0.09 秒。
- 后台预取前后两张照片，按顺序翻照片基本不用等待。
- 导出使用独立缓存，不会挤掉正在编辑的照片，导出时编辑器也不会卡住；导出时会提前解码下一张。批量导出 3 张全尺寸 JPEG 从约 12–13.6 秒降到约 3.5–4.7 秒。

## 说明

- v0.2.2 新加的 DNG 色调曲线基准，只作用于新版（v2）配方。v0.2.0 之前保存的 v1 配方仍然使用旧引擎，打开时会显示「Legacy edit preserved」；点「Use new controls」即可切到新基准（这会从中性状态重新开始调整，旧调整可撤销找回）。
